# Course data

## Card and Krueger restaurant data

Assignments 02 and 05 use [card-krueger_1994.csv](card-krueger_1994.csv), observed public-use restaurant records from Card and Krueger (1994). Read the [data notes and dictionary](card-krueger_1994-data-notes.md) for the source archive, variable definitions, employment measures, missing values, and record identifiers. The file retains all 410 restaurants. Assignment 02 uses baseline observations available for each measure; Assignment 05 uses the same restaurants with complete employment components in both waves for every model, so its baseline means need not match Assignment 02.
